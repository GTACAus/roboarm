GTAC Wi-Fi Codes

  1. 1Open the iPad Camera
  2. 2Point it at your station's code
  3. 3Tap “Join Network”

Each code holds a standard Wi-Fi join string, for example WIFI:T:WPA;S:GTAC 1;P:robotarm;;. Network names are GTAC 1 to GTAC 100, with a space before the number. All use the password robotarm (WPA/WPA2). Use the arrow keys to change page.
