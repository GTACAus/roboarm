01/03

Change how your prosthetic moves

You can program your arm with blocks on the iPad. Each control on the remote has a number, and your code decides what happens when you use it: how far a motor turns, how fast, and in which direction.

◀ Home

02/03

Open the code canvas

  1. Connect your iPad to the arm's Wi-Fi (see the robotic arm steps).
  2. On the Remote tab, choose Advanced (code), then tap </> Code.
  3. The starting program is already there: each control turns its motor 5 degrees. The live remote on the right shows the same numbers as the blocks.
  4. Tap ▶ Run, then use the remote on the right to test it.

03/03

Change your code

  1. Tap a number in a turn block and change it: 5 is a small step, 90 is a quarter turn.
  2. Drag set Motor speed to slow / medium / fast from Motors to change how fast it moves.
  3. Try go to position to send a motor to an exact angle, or move all motors home.
  4. Tap ■ Stop, then ▶ Run again to try your changes. Your code is saved on the iPad.
